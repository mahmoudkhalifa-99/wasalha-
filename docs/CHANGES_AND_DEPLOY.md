# ملخص التعديلات وخطوات النشر

> كل ده اتكتب بدون تشغيل (مفيش Flutter SDK ولا Firebase emulator وقت الكتابة). جرّب قبل النشر.

## 1) جرّب محلياً
```
flutter pub get
flutter analyze
flutter test
cd functions && npm install && npm test        # اختبارات verification + settlement
cd ../rules_test && npm install && npm test     # اختبارات القواعد في emulator
```
أي خطأ تحليل/ترجمة أو اختبار فاشل = غالباً غلط في الكتابة، صلّحه قبل النشر.

## 2) النشر (مع بعض، بالترتيب ده)
1. `firebase deploy --only firestore:indexes` (استنى لحد ما الفهارس تخلص بناء).
2. `firebase deploy --only firestore:rules,storage`
3. `firebase deploy --only functions` (محتاج خطة Blaze).
4. ابنِ التطبيق ووزّعه. بعدها ظبط `minVersion` من لوحة الأدمن عشان النسخ القديمة تتحدّث.
5. Apps Script (`apps_script/Code.gs`): انسخ النسخة الجديدة وانشر إصدار جديد.

## 3) بعد النشر
- Firebase Console ← App Check: فعّل Enforce لـ Firestore وStorage بعد ما تتأكد إن النسخ بتبعت توكن.
- ضع روابط سياسة الخصوصية والشروط في `lib/constants.dart` (النص الحالي مسودة).
- ترحيل الصور القديمة (اختياري): `functions/scripts/migrate_images.js` (تجربة افتراضياً، `--apply` للتنفيذ؛ خد export قبلها).
- الأوردرات المنتظرة وقت النشر الأحسن تخلص أو تتلغى قبلها.

## 4) اللي اتضاف
- قواعد أوردرات بقائمة حقول وترتيب حالات، قبول عرض في transaction، العرض على أجرة التوصيل بس.
- تقييد القراءة (مستخدمين/أوردرات/عروض/شات)، قفل الإشعارات وحماية relay الـ Apps Script.
- Functions: تسوية المحفظة عند التسليم، تقييم الكابتن، انتهاء الأوردرات المعلقة، منع مشوارين لكابتن، تنضيف حساب محذوف.
- شاشات: أرباحي (كابتن)، تسوية عمولة وتسعير وتذاكر دعم وتقارير (أدمن)، دعم وشكاوى وإعادة طلب وزر طوارئ (مستخدم).
- Crashlytics، App Check، حد أدنى للنسخة، التسعير والعمولة من `config/pricing`.

## 5) حساب المطعم والعناوين المحفوظة
- **مطعم:** من لوحة الأدمن ← المستخدمين ← تعديل مستخدم: غيّر الرتبة لـ "مطعم" واختار المطعم. الحساب ده بيشوف أوردرات مطعمه بس (من غير تليفون العميل) ويقبل/يرفض ويحدّث التحضير (جاري التحضير ← جاهز)، والعميل بيتبلّغ بإشعار. رفض المطعم لا يلغي الأوردر تلقائياً: العميل بيتبلّغ ويلغي بنفسه.
- **عناوين محفوظة:** شريط فوق اختيار نقطة الوصول في شاشة العميل (حفظ الوجهة الحالية، بضغطة تتطبّق، حد أقصى 10).
- فهرس جديد مطلوب: `orders (restaurantId, status)` — اتضاف في `firestore.indexes.json`.

## 6) اللي مش موجود (قرارات منتج/خدمات خارجية)
كوبونات، بقشيش، جدولة طلبات، دفع إلكتروني، ترجمة/لغات تانية.
